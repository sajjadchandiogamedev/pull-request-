01THE IDEA

Think of a branch as a bookmark for your work.

Git keeps a pointer to a commit. When you create a branch, you give that pointer a new name. Commits you make on it move the new name forward; your other branch stays put.

02YOUR FIRST WORKFLOW

Three small moves.

01

Start a branch

Name the idea you want to work on. Your current branch stays untouched.

git switch -c feature/search
02

Make a commit

Change files, check your work, then save a snapshot on this branch.

git add .
git commit -m "Add search"
03

Look around

Switch branches to see each version. The unmerged work comes with you.

git switch main
